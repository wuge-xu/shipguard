# Architecture Decision Records

ADR 用于记录 ShipGuard 的重要架构决定、原因、替代方案和后果。

## 状态定义

- Proposed：已提出，尚未采用。
- Accepted：已经采用。
- Superseded：已被新的 ADR 替代。
- Rejected：经过讨论后未采用。
